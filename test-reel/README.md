# Test reel — Creative Mind IT Services (9:16, 18s)

`clips/` contains 6 animated scenes (1080×1920, 30fps, 3s each): Hook → Brand → Web & App → Cloud & IT → Marketing → CTA.
`preview_reel.mp4` is the joined reel, so you can see the result.

## Build it in Premiere with Claude Motion
1. Open the Claude Motion panel and set Connection to **Free — copy/paste**.
2. Type anything (e.g. `build reel`) and press **Send**.
3. In the paste box, paste the full contents of `build_reel.jsx` wrapped in a jsx code block, then press **Use reply** → **▶ Run**.
4. Choose the `clips` folder. The script creates the bin, a 9:16 sequence, scene markers and cross dissolves.
5. Add music on A1, then export (H.264, 1080×1920).
